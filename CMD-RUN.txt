پیش‌نیاز: مخزن عمومی باشد، فایل telegram-large-downloader.zip در شاخهٔ main قرار گرفته باشد، و Docker Desktop نصب و در حال اجرا باشد. در CMD ویندوز کل این خط را کپی و اجرا کن:

powershell -NoProfile -ExecutionPolicy Bypass -Command "$ErrorActionPreference='Stop'; $t=Join-Path $env:TEMP 'tgdl-bootstrap'; if(Test-Path $t){Remove-Item $t -Recurse -Force}; New-Item -ItemType Directory -Path $t|Out-Null; Invoke-WebRequest 'https://github.com/arefhere51/telegram-large-downloader/archive/refs/heads/main.zip' -OutFile (Join-Path $t 'repo.zip'); Expand-Archive (Join-Path $t 'repo.zip') (Join-Path $t 'repo') -Force; $z=Get-ChildItem (Join-Path $t 'repo') -Recurse -File -Filter '*.zip'|Select-Object -First 1; if(!$z){throw 'Upload telegram-large-downloader.zip to the repository main branch first.'}; Expand-Archive $z.FullName (Join-Path $t 'project') -Force; $s=Get-ChildItem (Join-Path $t 'project') -Recurse -File -Filter 'install.ps1'|Select-Object -First 1; if(!$s){throw 'The ZIP is missing install.ps1.'}; & $s.FullName"

بار اول، نصب‌گر فایل .env را می‌سازد و باز می‌کند. توکن BotFather، Telegram API ID و API Hash و شناسهٔ عددی خودت را وارد کن، فایل را ذخیره و Notepad را ببند؛ سپس در پنجرهٔ نصب‌گر Enter بزن. داده‌ها در %USERPROFILE%\telegram-large-downloader\data می‌مانند.
